### Coding with AI (ChatGPT, Gemini, Meta AI)

2026-08-18

*Composing Functions* — AI is good at this task. It tends toward performance-optimal code, so clever and elegant design trade-offs are sometimes overlooked. AI still needs guidance for this. There are times when I prefer readability over pure speed, but usually AI has good suggestions for improvements.

*Code Reviews* — AI is good at this task. If prompted, it will generate positive and negative feedback, and it will rank the code on a bell curve across several dimensions. It can also examine code and **sometimes** accurately evaluate its runtime behavior. It is capable of explaining what code is doing—I would use Meta AI to help me understand new code.

*Prototyping UIs* — Meta AI can generate a relatively sophisticated UI/UX, especially if it has code to base its prototype on. However, it struggles to make incremental changes. It will generate a UI, take incremental feedback, but change everything.

### Games

These are lightweight games. Each required about a half day of coding. Tic-Tac-Toe and Minesweeper will play on your desktop if you download the source and open index.html.

These are good projects for beginning programmers. Tic-Tac-Toe and Minesweeper each include one or two complexities that make them fun challenges.

If you need help, Meta AI will help you.
